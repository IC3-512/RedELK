## Conventions used here

- Commands prefixed with nothing run on the **RedELK server**, in the repository root.
- Commands prefixed with `redir1$` or `c2server1$` run on that **host**.
- `redelk.yml` is the only file you edit. Anything else that looks editable carries a
  `generated by redelkctl` header and is overwritten by `./redelkctl generate`.
