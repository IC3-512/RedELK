# redelk-client

Copies one generated package to a redirector or C2 server and runs the installer inside it.

`./redelkctl generate` writes `build/packages/<name>/` per host: `filebeat.yml`, `inputs.d/` for
that host's C2 or redirector type only, the RedELK CA (plus this host's client certificate when
`server.tls.mutual_auth` is on), the log-sync cron and helper scripts for file-based C2 servers,
a `manifest.json` and a self-contained `install.py`. This role does the two things Ansible is good
at: putting that directory on many hosts and running `sudo ./install.py` there.

## Which package a host gets

`build/packages/{{ redelk_package_name }}/`, and `redelk_package_name` defaults to the inventory
host name. **That is the link between `inventory.yml` and `redelk.yml`**: a `c2_servers` or
`redirectors` entry named `redir1` produces `build/packages/redir1/`, which is installed on the
inventory host named `redir1`. Set `redelk_package_name` explicitly when the two names cannot be
the same.

API-based C2 servers (`mythic`, `outflankc2`) get no package - the RedELK server polls them - so
they must not appear in the inventory.

## What the installer does on the host

`install.py` is generated by redelkctl and documented in the package's own `README.md`. In short:
it adds the Elastic apt repository, installs and pins filebeat to the version in `redelk.yml`,
writes `/etc/filebeat/{filebeat.yml,inputs.d/,certs/}`, removes inputs left behind by an older
RedELK install, and - on file-based C2 servers - creates the `scponly` user with a restricted
`rush` shell, authorises the RedELK server's ssh key and installs the log-sync cron job.

## When it runs

Ansible cannot see whether `install.py` changed anything, so the installer runs only when there is
a reason to:

- the package that was copied differs from what is already on the host, or
- `/etc/filebeat/filebeat.yml` does not exist yet, or
- `redelk_client_force_install: true`.

That makes a second run of the playbook come back clean.

## Variables

| Variable | Default | Meaning |
| --- | --- | --- |
| `redelk_packages_path` | `{{ redelk_repo_path }}/build/packages` | Where the packages are |
| `redelk_package_name` | `{{ inventory_hostname }}` | Which package this host gets |
| `redelk_remote_base_path` | `/opt/redelk` | Parent of the staged package |
| `redelk_client_package_path` | `{{ redelk_remote_base_path }}/{{ redelk_package_name }}` | Staging directory (`0700`, it holds a private key) |
| `redelk_client_install_args` | `[]` | Extra installer flags, e.g. `["--no-filebeat"]` |
| `redelk_client_force_install` | `false` | Run the installer even when nothing changed |

## Requirements

- Debian or Ubuntu with `apt` on the target: `install.py` refuses anything else, and says what to
  do by hand instead.
- `become: true`.
- Outbound network access on the host for the Elastic apt repository, unless you pass
  `--no-filebeat`.

## Removing RedELK from a host

```bash
ansible-playbook -i inventory.yml playbook.yml --limit redir1 --tags client \
  -e 'redelk_client_force_install=true' -e '{"redelk_client_install_args": ["--uninstall"]}'
```
